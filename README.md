## English

### Quick Start

| Platform | Step 1 | Step 2 | Step 3 |
|----------|--------|--------|--------|
| **Windows** | Double-click `setup.bat` | Restart VS Code | Open folder → .cpp → F5 |
| **Linux** | `bash setup-linux.sh` | Restart VS Code | Open folder → .cpp → F5 |
| **macOS** | `bash setup-mac.sh` | Restart VS Code | Open folder → .cpp → F5 |

### What Gets Installed

| | Windows | Linux | macOS |
|---|---------|-------|-------|
| Compiler | GCC 16 (MSYS2) | g++ (apt/dnf/pacman) | clang++ (Xcode) |
| Debugger | GDB 17 | GDB | LLDB |
| Extension | ms-vscode.cpptools | ms-vscode.cpptools | ms-vscode.cpptools |

### Files

```
├── setup.bat              Windows installer (animated)
├── setup.ps1              PowerShell script
├── setup-linux.sh         Linux installer (animated)
├── setup-mac.sh           macOS installer (animated)
├── .vscode/               Auto-generated by setup
├── demo.cpp               Example code
├── README.md
└── LICENSE
```

### Debug Keys

| Key | Action |
|-----|--------|
| F5 | Build + Debug |
| F9 | Toggle breakpoint |
| F10 | Step over |
| F11 | Step into |
| Shift+F11 | Step out |

### Platform Notes

- **Windows**: Use English filenames only. Add `system("pause");` to keep console open.
- **Linux**: Auto-detects apt/dnf/pacman/zypper. Output in integrated terminal.
- **macOS**: Uses LLDB (no code signing needed). First run installs Xcode CLI tools.

### Troubleshooting

| Issue | Fix |
|-------|-----|
| `xxx.exe does not exist` | Save (Ctrl+S), use English name, F5 |
| Old output after edit | Close debug window, F5 again |
| GDB/LLDB not found | Restart PC, re-run setup |
| Shell permission denied | `chmod +x setup-*.sh` |

## 中文

### 快速开始

| 平台 | 第一步 | 第二步 | 第三步 |
|------|--------|--------|--------|
| **Windows** | 双击 `setup.bat` | 重启 VS Code | 打开文件夹 → .cpp → F5 |
| **Linux** | `bash setup-linux.sh` | 重启 VS Code | 打开文件夹 → .cpp → F5 |
| **macOS** | `bash setup-mac.sh` | 重启 VS Code | 打开文件夹 → .cpp → F5 |

### 安装内容

| | Windows | Linux | macOS |
|---|---------|-------|-------|
| 编译器 | GCC 16 (MSYS2) | g++ (apt/dnf/pacman) | clang++ (Xcode) |
| 调试器 | GDB 17 | GDB | LLDB |
| 扩展 | ms-vscode.cpptools | ms-vscode.cpptools | ms-vscode.cpptools |

### 文件结构

```
├── setup.bat              Windows 安装脚本（动画版）
├── setup.ps1              PowerShell 脚本
├── setup-linux.sh         Linux 安装脚本（动画版）
├── setup-mac.sh           macOS 安装脚本（动画版）
├── .vscode/               安装时自动生成
├── demo.cpp               示例代码
├── README.md
└── LICENSE
```

### 调试快捷键

| 按键 | 功能 |
|------|------|
| F5 | 编译 + 启动调试 |
| F9 | 当前行切换断点 |
| F10 | 逐行跳过 |
| F11 | 进入函数 |
| Shift+F11 | 跳出函数 |

### 平台注意事项

- **Windows**：文件名必须用英文。代码末尾加 `system("pause");` 防止窗口一闪而过。
- **Linux**：自动检测 apt/dnf/pacman/zypper。输出在集成终端。
- **macOS**：使用 LLDB（免签名）。首次运行会安装 Xcode CLI 工具。

### 常见问题

| 问题 | 解决 |
|------|------|
| `xxx.exe does not exist` | 保存(Ctrl+S)，用英文文件名，再 F5 |
| 改了代码结果没变 | 关闭调试窗口，再 F5 |
| GDB/LLDB 未找到 | 重启电脑，重运行 setup |
| Shell 权限拒绝 | `chmod +x setup-*.sh` |
